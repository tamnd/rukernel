# The Linux code that each LTP test checks, for the links in the result tables.
# Each line has a key, a tab and one or more paths in the Linux tree, with a space between them.
# A key is a test name (fork01), or a directory of the LTP sources under testcases (kernel/syscalls/fork).
# report.py uses the test name first, then the directory of the source of the test, then its parents.
# A path that ends with "/" is a directory. report.py stops if a path is not in the Linux tree.
# The lines of kernel/syscalls come from the SYSCALL_DEFINE of each system call in Linux.
