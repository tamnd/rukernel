# The LTP tests that the ltp boot test runs, one name on each line. tools/ltp/build.sh builds them.
# A test that is not in this list does not pass yet, or cannot pass for a reason below.
# tools/ltp/kconfig tells LTP the kernel options of rukernel.
#
# clone08 and clone10 use CLONE_THREAD or CLONE_SETTLS, and the clone function of musl refuses them
# with EINVAL. clone09 needs network name spaces. clone11 needs kernel options that rukernel does
# not have. fork13 forks until its run time is over, and fork14 maps 16 TiB and forks after each
# GiB. They are too slow for the boot test. mremap06 needs fallocate, and mremap07 needs kernel
# options that rukernel does not have. msync04 needs a block device. mlock02 needs user IDs, and
# mincore04 needs a page cache that processes share. setrlimit01 and setrlimit06 need the kernel to
# enforce the limits, and setrlimit02 needs user IDs. futex_waitv03 needs System V shared memory.
#
# sigwaitinfo01 and sigtimedwait01 wait for an empty set of signals, and the wrappers of musl call
# the system call again after EINTR, so the tests do not stop. rt_sigsuspend01, rt_sigaction01 and
# rt_sigprocmask01 read sa_restorer from the old action, and musl does not give it. timer_settime03 sets a time before the epoch,
# because CLOCK_REALTIME starts at 0 at boot. tgkill02 needs RLIMIT_SIGPENDING. kill05 needs System
# V shared memory, and kill13 needs a kernel with UBSAN.
#
# waitid10 reads /proc/sys/kernel/core_pattern, and the kernel does not have /proc/sys yet.
