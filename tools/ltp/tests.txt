# The LTP tests that the ltp boot test runs, one name on each line. tools/ltp/build.sh builds them.
# A test that is not in this list does not pass yet, or cannot pass for a reason below.
# tools/ltp/kconfig tells LTP the kernel options of rukernel.
#
# clone08 and clone10 use CLONE_THREAD or CLONE_SETTLS, and the clone function of musl refuses them
# with EINVAL. clone09 needs network name spaces. clone11 needs kernel options that rukernel does
# not have. fork13 forks until its run time is over, so it is too slow for the boot test. fork14
# maps 1 GiB 16384 times. With the 512 MiB of the boot test, the overcommit check refuses each map,
# as on Linux, and the test gives TCONF and checks nothing. mremap06 needs fallocate, and mremap07
# needs kernel options that rukernel does not have. msync04 needs a block device. mlock02 needs user
# IDs, and mincore04 needs a page cache that processes share. setrlimit01 and setrlimit06 need the
# kernel to enforce the limits, and setrlimit02 needs user IDs. futex_waitv03 needs System V shared
# memory.
#
# sigwaitinfo01 and sigtimedwait01 wait for an empty set of signals, and the wrappers of musl call
# the system call again after EINTR, so the tests do not stop. rt_sigsuspend01, rt_sigaction01 and
# rt_sigprocmask01 read sa_restorer from the old action, and musl does not give it. timer_settime03 sets a time before the epoch,
# because CLOCK_REALTIME starts at 0 at boot. tgkill02 needs RLIMIT_SIGPENDING. kill05 needs System
# V shared memory, and kill13 needs a kernel with UBSAN.
#
# waitid10 reads /proc/sys/kernel/core_pattern, and the kernel does not have /proc/sys yet.
# ptrace02 needs user IDs. ptrace04 and ptrace07 do not apply to x86_64 with this LTP build.
#
# epoll_wait05 needs AF_INET sockets. epoll_wait10 polls /proc/mounts for a change of the mounts, and the
# files of /proc cannot do poll yet. timerfd04 needs time name spaces. epoll_wait04 of this LTP version
# allows 1 ms for epoll_wait with a timeout of 0. Under QEMU without KVM, the first call runs kernel
# code that QEMU did not translate yet, and that can take longer. LTP after this version multiplies
# the limit by LTP_TIMEOUT_MUL.
#
# nice04, setpriority02, sched_setaffinity01, sched_setparam05, sched_setscheduler02 and
# sched_setscheduler03 need user IDs. sched_setscheduler04 calls sched_getscheduler of musl, which
# always gives ENOSYS.
#
# fgetxattr02 opens a loop block device, and the kernel has no loop driver. setxattr03 needs the
# immutable flag of FS_IOC_SETFLAGS.
#
# mq_open01 expects EINVAL for the name "", which the mq_open of glibc gives. musl calls the
# kernel, and Linux gives ENOENT, as rukernel does. msgctl05 needs the time_high fields of
# msqid64_ds, which the x86_64 headers of musl do not have. msgstress01 runs for minutes.
